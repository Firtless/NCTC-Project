# NCTC

## NCTC is a terminal-based application I created for myself. It combines a **Notepad**, **Calendar**, **Timer**, and **Calculator** into a single workflow.

## 📌 Navigation Note:

- To run the full integrated application from one main entry point, navigate to dev_proto. If you prefer to view or run the individual code modules separately, check out Note.py, Cal.py, Calc.py, and Timer.py. Feedback and pull requests for improvements are greatly appreciated!

---

## 🛠 Features

- **Notes:** The primary focus of this application. It offers a reliable, 100% private way to save personal notes—and look cool doing it. Designed specifically for users who want the absolute bare-bones note-taking experience without leaving the terminal.
- **Calendar:** A CLI-focused calendar that acts like a standard calendar, but with a major emphasis on properly handling holidays—something many standard calendar apps fail at.
- **Timer:** A lightweight floating utility that tracks active elapsed time with precise sub-second accuracy, featuring a clean dark interface with controls to stay focused.
- **Calculator:** A built-in utility so you can easily do quick math while taking notes without exiting the terminal, saving both RAM and screen space.
